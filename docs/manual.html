What is this?

The Legend of Zelda: Twilight Princess as a real PS4 program, not an emulator. It is based on Dusklight, the PC port of the game's fan decompilation. On the PS4 it runs at up to 60 FPS, optionally with HD textures, with PlayStation buttons and the Wii U-style HUD (Twilight HD).

This folder contains no game data. You bring your own game; the Setup Studio builds a package with it for your PS4.

What you need

The game filesYour own disc, dumped as an .iso. GameCube (GZ2E01, GZ2P01, GZ2J01) works directly, nothing else needed. Wii (RZDE01, RZDP01, RZDJ01) works directly when decrypted; an encrypted Wii dump (as CleanRip makes it) works together with your Wii key. WBFS/RVZ files and the Wii U HD version cannot be used.
How to dump your own disc: wii.hacks.guide/dump-games.html (with CleanRip)
Wii key (encrypted Wii dumps only)Paste your Wii's common key (32 hexadecimal characters) into the assistant, or give it the keys.bin that BootMii writes to the SD card together with a NAND backup of your own Wii: wii.hacks.guide/nand-backup.html. The Setup Studio contains no Nintendo keys.
The textures (optional)Henriko's "Twilight Princess 4K" pack, 1080p version for Dusklight (PC), and optionally the "Xbox + PS UI Buttons Addon" (PC) for PlayStation symbols on all buttons. Both are on Henriko's page. ZIP or extracted folder, both work: henrikomagnifico.com/zelda-twilight-princess-4k. The 4K version needs far more graphics memory and can stutter.
PS4 or PS4 Prowith GoldHEN (homebrew enabled)
ComputerWindows (64-bit), macOS (Apple silicon or Intel) or Linux (64-bit). Nothing to install: everything the Setup Studio needs is in this folder.

Without the texture pack the game runs with its original textures; the HD textures are purely an extra.

Start the Setup Studio

Double-click the file for your system in the release folder:

WindowsDusklight Setup Studio (Windows).bat
macOSDusklight Setup Studio (macOS).command. The first time: right-click → "Open" → "Open". The window app is then unpacked once into your Application Support folder, which takes a moment.
LinuxDusklight Setup Studio (Linux).sh. If a text editor opens instead, run sh "Dusklight Setup Studio (Linux).sh" in a terminal.

The assistant opens in its own window. If the window app cannot start, the launcher opens the assistant in your browser instead; everything works the same, only files you drag in are copied into the work folder first.

If nothing starts at all, copy the whole release folder to your computer and start it from there; some systems do not run programs straight from a USB stick.

The assistant, step by step

  1. Game: drag your .iso (GameCube or Wii) into the window, or choose it with "Browse…". It shows the game, version and region. If it is an encrypted Wii dump, the section "Wii dump? Add your Wii key" opens: paste your Wii key there, or drag in your keys.bin. The key is only used on your computer and never saved.
  2. HD textures (optional): drag the texture pack and the button addon into the window, folders or ZIPs, together or one by one; the assistant tells them apart. Or "Without textures".
  3. Settings: first how to install: a complete package (recommended, no FTP needed) or sending everything to the PS4 over FTP. Then the game language (every language your disc offers), the Wii U-style HUD, faster scene transitions, and the version: Dusklight (recommended) or Dusklight Dev (frame counter and tools for troubleshooting).
  4. PS4 (FTP only): switch on GoldHEN's FTP server, enter the PS4's IP address and "Test connection".
  5. Build / Install: the assistant makes your image smaller (a 4.4 GB Wii disc becomes about 1.1 GB; an encrypted dump is decrypted on the way; every file is checked), converts the textures, and builds the package or sends everything to the PS4. A complete package is about 3 GB, takes a minute or a few, and is saved in the folder you started the Setup Studio from.

Installing on the PS4

Complete package

  1. The Setup Studio saves Dusklight-Complete.pkg in the folder you started it from (where the launchers are).
  2. Copy Dusklight-Complete.pkg to the top folder of a USB drive formatted as exFAT.
  3. Plug the drive into the PS4 and install the package with the Package Installer (Settings → Debug Settings → Game → Package Installer, available with GoldHEN).
  4. Start Dusklight from the home screen.

The settings you chose apply when Dusklight starts for the first time. If Dusklight was set up on this PS4 before, it keeps its existing settings; change them in the Dusklight menu (touchpad).

Over FTP

  1. After the assistant has finished, open GoldHEN → Package Installer on the PS4 and install Dusklight.pkg (or Dusklight-Dev.pkg).
  2. Start Dusklight from the home screen.

Controls

The buttons sit where they are on the Nintendo controller, with PlayStation symbols:

CircleA – confirm, action
CrossB – back, sword
Triangle / SquareX / Y – items
TouchpadDusklight menu (settings, graphics, HD textures on/off)

Updating, saves and backups

  • For a new version, run the Setup Studio of the new release again and install the new package. Your saves are kept.
  • Saves and settings live on the PS4 in /data/dusklight-ps4/user/, separate from the program; reinstalling does not delete them.
  • The FTP way backs that folder up to your computer first, into DskStudioC06f/backups/ in your home folder.
  • DskStudioC06f also keeps the smaller image and the converted texture pack, so a second run is quick. Delete the folder whenever you need the space.

Troubleshooting

ProblemSolution
"This Wii image is encrypted"Add your Wii key in the section "Wii dump? Add your Wii key": paste it, or drag in your keys.bin (BootMii backup).
"This Wii key does not fit the disc"It is not the Wii's common key; take the keys.bin BootMii wrote next to nand.bin.
The image is rejectedThe message says why: usually a WBFS/RVZ file, which has to be converted to an ISO first.
"No connection to the PS4" (FTP)Is GoldHEN's FTP server on? Is the IP right? Are both in the same network? Some guest Wi-Fi networks keep devices apart.
Game does not start, black screenRestart the PS4 completely and try again.
Error CE-34878-0 (crash)Restart the PS4 completely, not just rest mode; otherwise the game can run very slowly afterwards. If it happens again, play with Dusklight Dev and send its logs to the developers.
No HD texturesIn the Dusklight menu (touchpad), check under graphics that texture replacement is on.
Disc check notice at startNormal for decrypted Wii images: choose "Continue anyway".
